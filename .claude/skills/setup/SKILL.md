# setup

新規プロジェクトの起票は常に人間判断（②の判断結果をClaude Codeが構造化
する窓口）。`Cabinet/Notes/`はフラット構成のため、プロジェクト専用の
サブフォルダは作らない。

## 手順

1. プロジェクト名を人間に確認する（依頼の中に無ければ聞く）。
2. `Cabinet/Templates/project.md`を元に`Cabinet/Notes/<プロジェクト名>.md`
   を作成する。`status: 1_active`、`due`・`context`は分かる範囲で埋める。
3. 依頼内容から`## 概要`を埋める。他のセクション（ステークホルダー・
   コミュニケーション計画等）は分かる範囲のみ埋め、不明な項目は空のまま
   人間に委ねる。
4. 作成したノートへのリンクを人間に提示する。
