あなたはこのObsidian vaultにおける新規プロジェクトの起票を担当する。
以下の手順に従うこと。

各手順のコードブロックに記載したコマンドは、`<...>`部分の置き換え以外を改変せずそのまま実行する。
確認・検証目的であっても、記載の無いコマンド（別のBash/PowerShellコマンドでの再確認等）を独自に追加実行しない。

## 1. 日次ブランチの確認

`30_Work`はこのvaultリポジトリの管理下にある。
プロジェクトノート・フォルダを作成する前に、vaultのCLAUDE.md運用ルールに従い、今日の日次ブランチ（`daily/YYYY-MM-DD`）にいることを確認する。
mainブランチにいる場合は`git checkout -b daily/<今日の日付>`で作成する（既に存在すればチェックアウトのみ）。

## 2. プロジェクト名の確認

ユーザーの依頼文にプロジェクト名が含まれていれば、それを使う。含まれていなければユーザーに聞き返す。

`30_Work/<プロジェクト名>/`が既に存在するか`Test-Path`で確認する。

```powershell
Test-Path -Path "<vaultルート>\30_Work\<プロジェクト名>"
```

既に存在する場合は、上書きせず、その旨をユーザーに報告して確認を取ってから続行する。勝手に既存フォルダに手を入れない。

## 3. 概要のヒアリング

`AskUserQuestion`または対話で「このプロジェクトの概要（目的・スコープ）」を1問だけ聞く。
ステークホルダー・コミュニケーション計画・マイルストーン・依存関係・成果物・完了の定義・リスク・課題・意思決定記録・参考リンクは聞かず、テンプレートのまま空欄にする。

## 4. プロジェクトノートの作成

`92_Template/project.md`の内容をコピーし、`30_Work/<プロジェクト名>/<プロジェクト名>.md`として新規作成する。

- frontmatterの`type: project`・`status: 1_active`はテンプレート通り。`due`・`context`は空欄のまま。
- 本文の`## 概要`見出し配下のみ、手順3でヒアリングした内容で埋める。
- 他のセクションはテンプレートの雛形（プレースホルダーの説明文・空の箇条書き）をそのまま残す。

`02_議事録/`について: today skillが自動生成する議事録ノートは仕様上`30_Work/`直下に作成され、このフォルダには入らない（今回は連携させない）。当面は空、または手動で移動したノートのみが入るフォルダになる。

Gitは空フォルダを追跡しないため、末端の各フォルダ（サブディレクトリを持つ場合はサブディレクトリ側のみ）に空の`.gitkeep`ファイルを置いて追跡されるようにする。

複数行のPowerShellループはBashツール経由の実行時に変数展開が崩れることが確認されているため、Bashの`mkdir -p`/`touch`で作成する（`cd`は使わずvaultルートからの相対パスをそのまま使うこと。作業ディレクトリを移動すると以降のコマンドのパス解決を誤る）。

```bash
for f in "00_管理" "01_資料" "02_議事録" "03_計画" \
         "04_稟議発注/01_見積依頼" "04_稟議発注/02_見積書" "04_稟議発注/03_稟議" "04_稟議発注/04_発注" \

         "08_設計/01_OS設計" "08_設計/02_基本設計" "08_設計/03_詳細設計" \
         "09_検証/01_基本機能試験" "09_検証/02_相互接続試験" "09_検証/03_性能試験" "09_検証/04_障害試験" "09_検証/05_監視試験" "09_検証/06_手順試験" \
         "10_構築/01_電源投入手順" "10_構築/02_単体試験手順" "10_構築/03_監視接続手順" "10_構築/04_現用物理接続手順" "10_構築/05_現用論理接続手順" \
         "11_工事/01_施工設計" "11_工事/02_工事資料" "11_工事/03_装置工法書" "11_工事/04_構成図" \
         "12_運用引継/01_製品マニュアル" "12_運用引継/02_運用操作マニュアル" "12_運用引継/03_障害対処フロー" "12_運用引継/04_保守条件書" "12_運用引継/05_不具合管理" "12_運用引継/06_アラート一覧" \

  mkdir -p "<vaultルート>/30_Work/<プロジェクト名>/$f"
  touch "<vaultルート>/30_Work/<プロジェクト名>/$f/.gitkeep"
done
```
