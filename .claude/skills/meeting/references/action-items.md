# meeting: アクションアイテムのタスク化

`meeting/SKILL.md`から、既存の議事録ノート（`type: meeting`）1件に対する
アクションアイテムのタスク化を依頼された際に呼び出される。呼び出し元
（`today`の締め処理・ユーザーからの直接依頼のいずれか）から対象ノートの
パスを受け取って実行する。「今日」等の日付フィルタは呼び出し元の責務であり、
このファイルは対象ノートが何であれ同じ手順を適用する。

## 手順

1. 対象ノートの`## アクションアイテム`見出し配下の未チェック`- [ ] [[ノート名]]`
   を列挙する。ノート名が空（`[[]]`）の項目は処理対象から除外する。
2. 残った項目それぞれについて、対応する`ノート名`のファイルがvault全体
   （`30_Work/`配下に限らず`10_Inbox/`等も含む）に存在するか確認する。
   - 存在する場合: 既存ファイルを上書きせずスキップする。
   - 存在しない場合: `92_Template/task.md`を使い`30_Work/`へ新規タスクノート
     として作成する。`context`は対象議事録の`context`を継承する。作成時、
     `## 経過`見出し配下に「- 今日の日付: 議事録[[元の議事録ノート名]]の
     アクションアイテムより起票」と出典を1行記載する。
3. 作成したタスクノートの件数・対象ノート名を呼び出し元に返す（呼び出し元が
   ユーザーへの報告に使う）。
