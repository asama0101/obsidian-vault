# today

vault直下の`Today.md`を軸に、1日の秘書業務（Inbox仕分け・カレンダー確認・
期限確認・クリアデスク）を回すスキル。開始・更新・締めの3モードを持つ。

## モード判別

- vault直下に`Today.md`が存在しない → **開始**モード。
- 人間が「今すぐ締めて」「クリアデスクして」等、締めを明示指示した → **締め**モード。
- 現在時刻が22:00以降で、かつその日まだ締めモードを実行していない
  （＝`Today.md`がまだ存在する） → **締め**モード（自動）。
- それ以外（`/loop`からの定期呼び出し、または人間が「更新して」等指示した） → **更新**モード。

## 前提

- 実行前に必ず今日の日次ブランチ（`daily/YYYY-MM-DD`）にいることを確認する。
  無ければ`main`から`git checkout -b daily/<今日の日付>`で作成する。
- frontmatterスキーマ（`type`/`status`/`due`/`check`/`date`/`context`）は
  変更しない。
