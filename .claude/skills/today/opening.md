# 開始モード

1. 今日の日次ブランチを確認・作成する。
2. `Cabinet/Templates/today.md`を元に、vault直下に`Today.md`を新規作成する。
   frontmatterの`date`は今日の日付にする。
3. `Cabinet/MEMORY.md`が存在すれば読み込む（存在しなければ空として扱う）。
   持続的文脈（関係者・前提条件等）として、以降のブリーフィング作成の
   前提知識に使う。
4. Google Calendarで今日の予定を取得する。取得できた各予定について:
   - 同じ`calendar_event_id`を持つノートが`Cabinet/Notes/`に既に無ければ、
     `Cabinet/Templates/meeting.md`を元に新規作成する（タイトル・URL・
     開始/終了時刻・出席者・議題を自動反映）。
   - 定例会議（`calendar_series_id`が同じ）の場合、前回の同シリーズ議事録
     ノートを`Cabinet/Notes/`から検索し、「次回」欄の議題と未完了の
     アクションアイテムを新しいノートへ転記する。
   - カレンダー取得に失敗した場合は黙って諦めず、人間に通知する。
5. `Today.md`の`## ブリーフィング`を埋める。
   - `### 今日の予定`: 4で生成/更新した今日の議事録ノートへのリンクと開始
     時刻を、チェックボックス形式（`- [ ] `）で一覧化する。
   - `### 今日のタスク`: `Cabinet/Notes/`で`type: task`かつ`due`が今日以前
     （超過含む）または`status`が`1_todo`/`2_doing`のノートへのリンクを、
     チェックボックス形式（`- [ ] `）で一覧化する。
   - `### 一言`: その日の予定・タスク、および3で読み込んだ
     `Cabinet/MEMORY.md`の内容から特に重要そうな1件を選び、一言コメント
     を書く（例:「今日はAさんとの会議が重要です」）。
6. `PushNotification`で朝のブリーフィング完了を通知する。
7. `/loop`スキルを使い、`.claude/skills/today/update.md`の手順を30分間隔で
   自己ペース実行するよう設定する（`Skill`ツールで`/loop`を呼び、プロンプト
   には「`today`スキルの更新モードを実行してください」を渡す）。人間が
   明示的に停止するか、締めモードが実行されるまで継続する。
