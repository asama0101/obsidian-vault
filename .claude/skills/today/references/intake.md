# 取り込み

会話に貼られた本文からノートを作る。

1. 依頼内容・締切・関連する案件を読み取る。
2. 下の分類基準で `type` と `tags` を決める。旧 `setup` スキルが担っていた新規プロジェクトの起票もこの経路に含まれる。「〇〇案件を起票して」のような指示は、分類基準で `project` と判定して `new_note.py --type project` を実行する経路になる。
3. `new_note.py` でノートを作り、原文全体を `task` なら `## 作業ログ`、`project` なら `## 概要`、`meeting` なら `## メモ`、`know-how` なら `## 状況` に残す。
4. 作ったノートのパスを人間に伝える。
