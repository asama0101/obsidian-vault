# today: タスク注記ルール

`## 今日のタスク`欄の対象タスク検索条件、および`due`/`check`の期限超過注記ルール。`opening.md`・`update.md`・`closing.md`から共通で参照される。

## 入力

なし（検索条件は固定）。

## 検索条件

`30_Work/`配下の`type: task`ノートのうち、`status`が`3_done`ではなく、かつ`due`が今日以前または`check`が今日以前のもの。

## 注記ルール

注記形式: `- [ ] [[ノート名]]**（due YYYY-MM-DD超過）**`

検索条件と揃え、以下の優先順位で1つだけ注記する。

1. `due`が設定されており今日以前の場合:
   - `due`が今日より前 → `**（due YYYY-MM-DD超過）**`
   - `due`が今日と同日 → `（due YYYY-MM-DD）`（「超過」を付けない）
2. 上記に該当せず、`check`が設定されており今日以前の場合:
   - `check`が今日より前 → `**（check YYYY-MM-DD超過）**`
   - `check`が今日と同日 → `（check YYYY-MM-DD）`（「超過」を付けない）

## 出力

検索条件に合致するタスクの一覧（注記ルール適用済みの`- [ ] [[ノート名]]（...）`形式の行）。
