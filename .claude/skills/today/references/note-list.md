# today: 今日作成・更新したノート一覧の生成

`.claude/skills/today/references/update.md`・`.claude/skills/today/references/closing.md`から呼ばれる、`## 今日作成・更新したノート`欄の内容を生成する共通ロジック。このファイル自体はデイリーノートへの書き込みを行わない（生成した文字列を返すのみ）。

## 入力

今日の日付（`YYYY-MM-DD`形式）。

## 手順

1. vaultルートで`git status --short -- 30_Work 40_Knowledge 10_Inbox`を実行する。
2. `??`（未追跡）を「作成」、`M`等の追跡済みファイルへの変更を「更新」とする。
3. 同名の`D`（削除）＋`??`（未追跡）のペアは、フォルダ移動によるものとみなし「更新」として扱う（新規作成ではない）。
4. typeごとにグルーピングした`- [[ノート名]]（作成）`/`- [[ノート名]]（更新）`のリストを作る。

## 出力

typeごとにグルーピングされた`- [[ノート名]]（作成）`/`- [[ノート名]]（更新）`のリスト文字列。

## 書き込み方（呼び出し元の責務）

- `20_Diary/<今日の日付>.md`の`## 今日作成・更新したノート`見出し配下を、この出力で置き換える。
- 見出しが無ければ`## メモ`見出しの直前に新設する。
- `## メモ`欄は手動更新されるため、常にノートの最後尾に保つ。
