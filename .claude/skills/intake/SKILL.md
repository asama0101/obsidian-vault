# intake

会話に貼り付けられたメール・チャット本文から、タスク候補を抽出し
`Cabinet/Notes/`へノート化するスキル。①捕捉のリッチ版という位置付け
（`Inbox/`への一言メモより詳細な内容を直接渡す経路）。

## 手順

1. 貼り付けられた本文から、依頼・締切・関連プロジェクトを読み取る。
2. `context`（既存プロジェクト名）と種別が明確に判定できるか確認する。
   `today`スキルの更新モード（`.claude/skills/today/update.md`）と同じ
   判定基準を使う。
3. 両方明確なら`Cabinet/Templates/{type}.md`を元に`Cabinet/Notes/`へ
   ノートを作成する。本文の要点を転記し、元のメール/チャット本文全体は
   `## メモ`に残す。
4. どちらか（またはどちらも）不明瞭なら、`Cabinet/Templates/review.md`を
   元に`Review/`へノートとして書き出す。`## サマリー`に依頼内容を3行程度
   で要約し、`## 本文`に元のメール/チャット本文全体を転記し、`source`
   プロパティは`intake`とする。`## 要判断`には、確信のある方（type or
   context）は候補として明示し、確信の持てない方のみ判断を仰ぐ形で書く。
5. 作成したノート（3または4のいずれか）へのリンクを人間に提示する。
