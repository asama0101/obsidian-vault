# デイリーノート運用

1日の作業はデイリーノートで回す。

## 開き方
- `/daily`を実行する（無ければ新規作成、あれば開く）
- 「今日のノート開いて」等の発言でも自動実行される（スキル化により文脈判断）
- 今日の日次git branch（`daily/YYYY-MM-DD`）も自動作成・チェックアウトされる

## 新規作成時に自動入力される内容
- `## スケジュール`: カレンダー連携があれば当日の予定を時刻順に列挙
- `## 議事録`: 会議候補から生成した議事録ノートへのリンク
- `## 今日のタスク`: 期限切れ・本日期限（`due`が今日以前）または本日チェック（`check`が今日以前）のタスク

## 常に最新化される内容
- `## 今日作成・更新したノート`: `/daily`実行のたびに再生成される（既存ノートを開く場合も）

## タスクの完了操作
- `## 今日のタスク`欄でチェックを付けると、`/wrapup`実行時に元タスクの`status`が完了になる
