# 1日を締める

1日の終わりに`/wrapup`を実行する。

## 自動修正される内容
- 今日作成・編集したノートの`context`補完
- 議事録アクションアイテムのタスク化
- Teams/Copilot議事録の転記（連携があれば）
- 今日のタスク欄でチェック済みの項目は、元タスクの`status`を完了に更新
- 「今日」更新のあったプロジェクトの`## 進捗`見出しを自動更新

## まとめて報告される内容
- 未完了の今日のタスク
- メモ欄からの昇格候補
- 明日の準備

## 自動整理される内容
- `30_Work`・`40_Knowledge`直下に置きっぱなしのノートを、プロジェクト・カテゴリのフォルダへ移動

## 最後に行われること
- 今日の変更をひとつのコミットにまとめる
- 日次ブランチを`main`へマージする
- `git push`する
