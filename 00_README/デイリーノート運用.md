# デイリーノート運用

1日の作業はデイリーノートで回す。

Claude Codeで`/daily`を実行する（無ければ生成、あれば開く）か、「今日の
ノート開いて」「デイリー始めたい」等の発言でも自動的に実行される（スキル化
により、Claude Codeが文脈から判断して起動する）。今日の日次git branch
（`daily/YYYY-MM-DD`）も自動的に作成・チェックアウトされる。カレンダー
連携があれば当日の会議候補から議事録の下書きも事前生成される。

新規作成時は、期限切れ・本日期限（`due`が今日以前）または本日チェック
（`check`が今日以前）のタスクが`## 今日のタスク`欄に自動で列挙される。
チェックを付けると、`/wrapup`実行時に元タスクの`status`が完了に更新される。
